Neon Harbor — an original 2D top-down open-world crime game in a sun-soaked harbour city. Explore on foot and by car, steal cars, dodge traffic and pedestrians, outrun the police at wanted levels 1–5, and run three story missions for Mara, the fixer on Dock Street: steal a car for her garage, courier a package to the beach cafe against the clock, and pull the Big Score with the whole force after you. Punch and pistol combat, a live minimap, cash and health HUD, a day clock, synthesized WebAudio sound, and a localStorage save. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.
